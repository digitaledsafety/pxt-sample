# Digital Education & Safety Foundation PXT Editor

This repo contains the Digital Education & Safety Foundation (DESF) editor built with [Microsoft MakeCode (PXT)](https://github.com/Microsoft/pxt).

## About DESF

[Digital Education & Safety Foundation](https://digitaleducationsafety.org/) is dedicated to empowering the underserved with a modern STEM/STEAM education.

## Running locally

### Setup

The following commands are a 1-time setup after syncing the repo on your machine.

* install [node.js](https://nodejs.org/en/)

* install the PXT command line
```
npm install -g pxt
```
* install the dependencies
```
npm install
```

### Running the local server

To open a local web server:
```
pxt serve
```

After making a change in the source, refresh the page in the browser.

## Deployment

The editor is automatically deployed to GitHub Pages via GitHub Actions.
